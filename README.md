# 🎒 Campus-Find – Lost and Found Web Application

## 📌 About the Project

Campus-Find is a functional Lost and Found web application developed as an academic group project.

The platform aims to simplify the process of reporting and recovering lost belongings within a university campus. It provides students with a digital space to report lost items, upload pictures and search for items reported by others.

## 🎯 Problem Statement

Students frequently lose personal belongings around campus. Finding these items can be difficult because there is no convenient centralised platform to connect people who have lost items with those who have found them.

Campus-Find aims to address this problem through a digital Lost and Found platform.

## ✨ Key Features

- Student registration and login.
- Reporting lost belongings.
- Uploading item pictures.
- Searching for lost and found items.
- Accessing information about reported belongings.
- User-friendly interface.

## ⚙️ How It Works

1. Students access the Campus-Find website.
2. They register or log in.
3. Students can report belongings they have lost or found.
4. Item pictures and relevant information can be uploaded.
5. Users can search for reported items.
